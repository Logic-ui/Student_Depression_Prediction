# Student Depression Prediction & Exploratory Data Analysis (EDA) System

An end-to-end Machine Learning, Data Analytics, Flask REST API, and modern React web application designed to explore, analyze, and predict university student depression risks using authenticated survey data.

---

> **Important Educational & Clinical Disclaimer**  
> This system is built strictly for educational, academic, and decision-support research purposes. Predictions generated by this machine learning model represent statistical risk estimates based on survey correlation patterns and **must NOT be presented, interpreted, or utilized as a clinical, psychological, or psychiatric diagnosis**. Any individual experiencing prolonged emotional or mental distress should consult a licensed healthcare professional or qualified university counseling service.

---

## 1. Project Overview & Objectives

Student mental well-being is heavily influenced by a combination of physical health status, academic pressures, relational stability, peer support circles, and socioeconomic backgrounds. The objective of this project is to:
1. Conduct comprehensive **Exploratory Data Analysis (EDA)** on empirical student survey records.
2. Formulate and benchmark multiple classification algorithms (**Gradient Boosting**, **Random Forest**, **Logistic Regression**, and **Decision Tree**) with 5-fold stratified cross-validation and holdout validation.
3. Overcome class imbalance (~27% depression prevalence) by optimizing for **Recall**, **Precision**, and **F1-Score** alongside overall accuracy.
4. Serialize and persist the preprocessor and trained production pipeline without data leakage.
5. Expose prediction and analytics services through a robust **Flask REST API**.
6. Provide an intuitive, responsive, and aesthetically modern **React** frontend dashboard featuring interactive charts, customizable risk evaluations, profile presets, and detailed model diagnostics.

## 2. Dataset Description & Structure

The system is trained and evaluated on `dataset/student_depression_dataset.csv`, consisting of **4,464 student survey observations** across **13 attributes**:

### Features Overview
| Feature Column | Type | Category | Description / Domain |
|---|---|---|---|
| `Gender` | Categorical | Demographic | `Female`, `Male` |
| `Age` | Numerical | Demographic | Student age (17 to 28 in dataset, valid 15-40) |
| `Family_background` | Categorical | Socioeconomic | `Middle class`, `Lower Middle class`, `Rich class` |
| `Relationship_status` | Categorical | Relational | `Single`, `In a Relationship`, `Complicated` |
| `Marital_status` | Categorical | Relational | `Unmarried`, `Married`, `Separated` |
| `Living_style` | Categorical | Lifestyle | `Bachelor` (mess/hostel/shared), `Family` (home) |
| `Current_semester` | Numerical | Academic | Semester number (0 to 13) |
| `CGPA` | Numerical | Academic | Cumulative Grade Point Average (2.25 to 4.00) |
| `friend_circle` | Categorical | Social Support | `Yes`, `No` |
| `Health_condition` | Categorical | Somatic Health | `Good`, `Normal`, `Abnormal`, `Critical` |
| `Cost_without_study` | Numerical | Economic | Monthly non-academic living expenditure (BDT) |
| `Home_division` | Categorical | Geographic | 8 divisions of Bangladesh |
| **`Depression` (Target)** | **Categorical (Binary)** | **Target** | **`Yes` (1,201 cases / 26.9%) vs `No` (3,263 cases / 73.1%)** |

### Data Quality & Integrity
- **Missing Values:** 0 across all 13 columns.
- **Duplicate Records:** 0 duplicate rows detected.
- **Data Leakage Prevention:** Preprocessing transformers (`StandardScaler` and `OneHotEncoder`) are fitted strictly on the training partition ($80\%$) and applied uniformly during inference.

## 3. Exploratory Data Analysis (EDA) Key Findings

1. **Physical Health is the Dominant Predictor:**
   - **Critical Health:** $100.0\%$ depression incidence ($634 / 634$).
   - **Abnormal Health:** $54.9\%$ depression incidence ($484 / 881$).
   - **Normal Health:** Only $4.6\%$ depression incidence ($83 / 1,787$).
   - **Good Health:** $0.0\%$ depression incidence ($0 / 1,162$).
   - *Insight:* Severe somatic/physical health disorders strongly co-occur with depressive symptoms.

2. **Protective Role of Peer Support (Friend Circle):**
   - Students without a friend circle had a **$34.3\%$** depression rate compared to **$24.0\%$** for students with an active peer group.

3. **Relationship Dynamics:**
   - Single students exhibited a **$35.9\%$** depression rate, significantly higher than students in romantic relationships (**$11.5\%$**).

4. **Socioeconomic Influence:**
   - Students from lower-middle-class families experienced **$30.6\%$** depression compared to **$17.6\%$** for students from rich class backgrounds.

5. **Academic Correlation:**
   - CGPA exhibits a negative correlation with depression ($-0.096$). Students in lower GPA bands ($<2.50$) experience higher academic anxiety and distress.

6. **Geographic Distribution:**
   - Northern and Western divisions (**Rangpur $32.0\%$**, **Rajshahi $31.6\%$**, **Khulna $31.0\%$**) recorded higher depression prevalence than Dhaka ($22.4\%$) and Sylhet ($23.6\%$).

## 6. Installation & Execution Guide

### Prerequisites
- **Python**: 3.9+ (Tested on Python 3.14)
- **Node.js**: v18+ (Tested on Node v24)
- **npm**: v9+

---

### Step 1: Backend Setup & Training

1. Open your terminal in the workspace root:
   ```bash
   cd d:\Student_Depression_Poject
   ```

2. (Optional) Create and activate a Python virtual environment:
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. Install required Python packages:
   ```bash
   pip install -r backend/requirements.txt
   ```

4. Train the models and generate serialization artifacts:
   ```bash
   python backend/scripts/train_model.py
   ```
   *This command evaluates all 4 classifiers, validates holdout test scores, exports Joblib models to `backend/models/`, and generates JSON artifacts for fast API responses.*

5. Start the Flask backend server:
   ```bash
   python backend/app.py
   ```
   *The Flask API will run on `http://127.0.0.1:5000`.*

---

### Step 2: Frontend Setup & Dev Server

1. In a new terminal window, navigate to the `frontend/` folder:
   ```bash
   cd d:\Student_Depression_Poject\frontend
   ```

2. Install frontend dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

3. Launch the Vite development server:
   ```bash
   npm run dev
   ```
   *The React application will be available at `http://127.0.0.1:5173/`.*

## 8. Troubleshooting Common Errors

1. **Port 5000 Already in Use:**
   If port 5000 is occupied by another process, specify an alternative port:
   ```bash
   $env:PORT=5001; python backend/app.py
   ```
   Then update `VITE_API_BASE_URL=http://127.0.0.1:5001/api` in `frontend/.env`.

2. **Model Files Missing (FileNotFoundError):**
   Run the training script to recreate serialized artifacts:
   ```bash
   python backend/scripts/train_model.py
   ```

3. **Node Peer Dependency Warnings with Recharts:**
   Use the legacy peer dependencies flag when installing frontend packages:
   ```bash
   npm install --legacy-peer-deps
   ```

4. **CORS Connection Refused:**
   Ensure Flask-CORS is installed and `python backend/app.py` is actively running before submitting requests from the React frontend.
